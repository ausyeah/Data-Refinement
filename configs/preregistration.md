> 因此位置门控在切片层面**系统性牺牲长尾内容**——聚合结论掩盖了切片代价。

## 2. 阶段 B 确认性终点（在阶段 B 任何结果之前冻结）

> **v1.1 修订（2026-09-08，依据 T2 机械零模型，见 §9）**：
> E1b（rarity×pos）经 T2 检验为**机械效应**——后缀截断模拟系数 −0.966 ≈ 观测 −0.916，
> 即交互完全由"尾截规则 × 源语料稀有-位置相关"复现，**不是清洗器稀有度感知的证据**，
> 降级为探索性操纵检查。真正承重的语料属性假设是 **E1c**，代价判断是 **E2**。

### 终点 1（机制 · 审计侧，阶段 A 正式化）
用**独立的校准切分**（此前探索用行已从正式评估中排除或标注）重估：

**E1a**（操纵检查）：位置主效应。M1 中 pos 系数 < 0。通过是任何截尾管线的必要条件，不单独作为发现。
**E1c**（承重 · 语料形状）：原始语料的稀有 token（zipf<2.5 的词典内词 + 内容词）随文档位置
单调后移。测量：token 级（非行级代理）位置分布；**限定知识承载词**
（排除 URL/纯数字/代码/单字母残片），并报告**文档内置换零分布**下的超额量（而非原始不等式）。
> 接触检验（探索样本，n=114 合格文档）：行级代理 null（p=0.38）——代理过粗，token 级版本待做。
> 若 E1c 在 token 级仍 null → 位置性清洗的稀有代价消失，叙事退化为"纯长度归一化"，kill 触发前置。

**E1b**（探索性操纵检查）：rarity×pos < 0 —— **T2 显示为机械效应，不再作为发现宣称**；
在论文中作为"清洗规则是位置性的（与机械尾截不可区分）"的支撑。

### 终点 2（代价 · 下游侧，阶段 B 探针 —— **本文真正的裁决点**）
在独立测试语料上（不参与任何阈值选择）：

**E2**：以稀有度分层的下游基准上，精炼语料训练的探针在 **tail 分层 delta ≤ 0**，
而 UltraX 宣称的聚合收益（若复现）集中在 head。
主统计量：tail 分层 delta（精炼−原始）的点估计 + 文档/采样级 bootstrap 95% CI。

### Kill criterion（预绑定）
- 若 E1c 在 token 级严格检验后 null → "位置性清洗牺牲稀有词汇"的机制叙事死亡，
  降级为纯长度归一化测量学；
- 若 E2 tail delta ≥ 0（精炼在尾部**也**更好）→ **本文假设整体死亡**：
  走 TOST 等价性检验（95% CI ⊂ ±δ_min），发表 informative null。

## 3. 探索性族（BH-FDR q=0.05，表内标 *）

词级消失分析（稀有知识 vs 稀有噪声）、实体通道、删除率十分位曲线、
跨语料强度差异的协变量解释（URL 密度 / 语言 / 长度分布）、
阈值敏感性、位置窗格（前/中/后三分）分桶、标题机制的细粒度检验。

## 4. 阶段 B 探针协议（冻结前仍需严复核审计，见修订日志）

- 模型：150M–500M（QLoRA/from-scratch 视规模），3–5 seeds，显式方差分解
- 语料版本：raw / refined / **tail-restored**（raw 尾截切回精炼 —— 反事实，用于归因尾截）
- 下游：稀有度分层的既有基准 + 自建切片，全部**分层报告**
- 禁用作难度代理：通过率、NLL（循环定义，见 v1 F1 教训）

## 5. 泄漏与访问纪律

- 阶段 A 的行样本带 `doc` 标识；确认性分析用**独立新切分**（题/文档级哈希 30/70）
- 所有阈值在校准切分上定；测试切分只终评一次，聚合输出
- 种子：≥3（目标 5）；bootstrap 纳入训练噪声
